# Daisy & Leo Design

Website for Daisy & Leo Design — hand-poured resin clocks, mirrors, calligraphy and
gifts. Next.js static export with a Remotion logo intro and a 3D gift box (three.js).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/ — deploy to any static host
```

See `CLAUDE.md` for all scripts and `DESIGN.md` for the design system.
